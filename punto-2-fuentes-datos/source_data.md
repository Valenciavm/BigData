

## Punto 2: Fuentes de Datos y Asignación de Infraestructura

Para cumplir con la simulación de fuentes heterogéneas exigida en el proyecto (RDS MariaDB, archivos locales en EC2 y endpoints web/URL), se integran y mapean los datasets de la siguiente manera:

| Dataset | Enlace Oficial / Fuente | Filas Reales | Componente AWS | Formato y Justificación Técnica |
| --- | --- | --- | --- | --- |
| **Distribuidores Mayoristas - Despacho** | [datos.gov.co (339g-zjac)](https://www.datos.gov.co/Minas-y-Energ-a/Distribuidores-Mayoristas-Despacho-de-combustibles/339g-zjac/about_data) | **7.18M** | **URL / API** | **Socrata API / CSV $\rightarrow$ Parquet**: Dataset masivo de hechos. Se ingiere vía HTTP directo al Data Lake (S3 Raw) para procesamiento distribuido con Apache Spark / EMR. |
| **Estaciones de Servicio Automotriz y Fluvial** | [datos.gov.co (fbht-2fzd)](https://www.datos.gov.co/Minas-y-Energ-a/Estaciones-de-Servicio-Automotriz-y-Fluvial-Despac/fbht-2fzd/about_data) | **6.48M** | **URL / API** | **Socrata API / CSV $\rightarrow$ Parquet**: Registros transaccionales masivos de estaciones de servicio descargados dinámicamente. |
| **IEA Monthly Electricity Statistics** | [Kaggle (ccanb23)](https://www.kaggle.com/datasets/ccanb23/iea-monthly-electricity-statistics) | **180K** | **Instancia EC2** | **CSV local en EC2 (`file_zip.csv`)**: Archivo descargado desde Kaggle y almacenado en `/home/ec2-user/data/iea-monthly-electricity-statistics/`. Se ingesta hacia S3 vía SSM igual que los demás archivos EC2. |
| **Ventas de GNCV** | [datos.gov.co (v8jr-kywh)](https://www.datos.gov.co/Minas-y-Energ-a/Consulta-Ventas-de-Gas-Natural-Comprimido-Vehicula/v8jr-kywh/about_data) | **135K** | **Instancia EC2** | **CSV plano local**: Simula logs/reportes operativos exportados en el almacenamiento local de un servidor Linux (`/var/data/gncv/`). |
| **Beneficio Zona de Frontera** | [datos.gov.co (shbt-hqy9)](https://www.datos.gov.co/Minas-y-Energ-a/Beneficio-de-estaciones-de-servicio-en-zona-de-fro/shbt-hqy9/data_preview) | **90.4K** | **Instancia EC2** | **CSV plano local**: Archivo de volumen medio almacenado localmente en EC2 para ingesta por lotes hacia S3. |
| **Productores B100 y Etanol** | [datos.gov.co (macx-96u2)](https://www.datos.gov.co/Minas-y-Energ-a/Productores-Productores-de-B100-y-Etanol-Alcohol-C/macx-96u2/about_data) | **47K** | **RDS MariaDB** | **Tabla SQL OLTP (`productores`)**: Catálogo maestro relacional con claves primarias, tipos de datos estrictos e integridad referencial. |
| **Agentes GNCV** | [datos.gov.co (ba2i-v4xx)](https://www.datos.gov.co/Minas-y-Energ-a/Consulta-Agentes-de-Gas-Natural-Comprimido-Vehicul/ba2i-v4xx/data_preview) | **1,761** | **RDS MariaDB** | **Tabla SQL OLTP (`agentes_gncv`)**: Dimensión relacional estructurada consultada mediante `mysqldump` / conectores JDBC en Spark. |
